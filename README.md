# Hi, I’m Anthony Clavery

Independent Data Platform, MLOps and AWS Consultant.

I help teams design, build and operate reliable data platforms, from cloud architecture and data pipelines to machine learning delivery and observability.

## What I work on

I come from production and operations.

My background was built around running systems, working with real operational constraints and taking responsibility when something needs attention.

Over time, I moved closer to development, first through data engineering and now through data platform and cloud architecture. That journey still shapes the way I work today: building a system is only part of the job. It also needs to be reliable, observable, cost conscious and easy to operate.

I believe in “you build it, you run it.”

## Areas of expertise

In practical terms, I work on AWS data platforms and cloud architectures, with a focus on data pipelines, data quality, MLOps, Infrastructure as Code, CI/CD and the operational foundations that keep systems running in production.
